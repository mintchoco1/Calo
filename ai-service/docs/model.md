* Zero-shot classification with SigLIP/CLIP
다른 모델들은 미리 정해진 N개 클래스 중 고르는 모델. 한 번 학습되면 그 외 음식은 영원히 모름
SigLIP 같은 모델은 좀 다르게 작동함. 구글이 만들었음
CLIP와 아키텍처는 거의 동일. CLIP는 Softmax loss - 한 배치 안의 모든 이미지-텍스트 쌍을 동시에 비교. 큰 배치일수록 계산이 폴발적으로 늘어남
SigLIP는 Sigmoid loss - 각 이미지-텍스트 쌍을 독립적으로 평가. 배치 크기를 훨씬 키울 수 있고 같은 자원으로 더 잘 학습됨
SigLIP2는 개선 버전. multilingual vision-language encoder - 다국어 지원 강화. 영어 위주에서 한국어 텍스트도 라벨을 줘도 동작함
localization, dense features 향상을 위해 decoder-based pretraining, self-distillation, masked prediction 같은 기법을 통함

Zero-shot 이란? -> 모델이 한 번도 보지 않은 클래스도 분류할 수 있다는 의미. 추론할 때 분류할 라벨을 텍스트로 직접 넘겨줌
candidate_labels = ["김치찌개", "비빔밥", "명란파스타", "제육볶음", ...]
result = model.classify(image, candidate_labels)
모델은 이미지를 보고 사용자가 제공한 라벨 목록 안에서 가장 그럴듯한 걸 고름. 핵심은 라벨 목록을 매번 자유롭게 바꿀 수 있음
